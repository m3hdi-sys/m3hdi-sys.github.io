[Endpoint Windows + Sysmon] ──┐ ├──► [Serveur Wazuh SIEM/XDR] ◄──► [API VirusTotal (Scan FIM)] [Serveur Linux + Auditd/SSH] ─┘ │ ├──► Réponse Active : Bannissement IP (iptables) └──► Script Python : Alerting temps réel (Webhook Discord)
